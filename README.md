# ATM System

A Java-based application simulating an ATM system with core banking functionalities and a graphical user interface.

## Features
- Withdrawals and deposits
- Account balance management
- Basic account operations with validation
- GUI-based interaction

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Key Concepts
- Modular design
- Error handling and input validation
- OOP principles such as classes and encapsulation

## What I Learned
- Designing structured applications using OOP
- Handling user input and errors effectively
- Building functional and interactive programs
